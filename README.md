# Remmy (Toxa) — Intelligent Daily Reminders, Habits & Focus OS UI

A modern smart reminder SaaS, habit tracking application, and productivity OS UI for **Remmy**, featuring a live web playground, natural language parsing simulation, interactive Pomodoro focus timer, and dark aurora glassmorphism.

## ✨ Features
- **Vibrant Dark Aurora SaaS Aesthetic**: Electric violet (`#8b5cf6`), neon magenta (`#ec4899`), Space Grotesk and Plus Jakarta Sans typography.
- **Interactive Remmy Web Playground**: Add dynamic tasks with custom tags (Focus, Habit, Personal), check items off, and increment your streak flame (`🔥`).
- **Integrated Pomodoro Focus Timer**: Functional 25-minute focus timer with Start, Pause, and Reset cycles.
- **Natural Language Parsing Simulation**: Contextual reminder previews with geo-fenced alarms and priority badges.
- **Bento Grid Superpowers & SaaS Tier Pricing**: Free Starter, Pro Mind ($4.99/mo), and Lifetime Zen.
